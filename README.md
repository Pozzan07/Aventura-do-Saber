# Aventura do Saber

Um jogo educativo infantil para aprender brincando. A criança escolhe um nível de dificuldade e responde a desafios de conhecimentos básicos em uma experiência interativa.


## Sobre o jogo

O Aventura do Saber foi criado como projeto de curricularização pelo Grupo 17. O jogo apresenta 30 perguntas divididas em três níveis — Fácil, Médio e Difícil — com atividades de múltipla escolha e desafios de arrastar e soltar.

Cada nível contém 10 perguntas. As respostas corretas valem 10 pontos, e ao final da rodada a criança pode conferir o resultado e jogar novamente.

## O que você encontra

- Uma tela inicial para começar a aventura.
- Três níveis de dificuldade.
- Perguntas sobre linguagem, números, formas, cores, animais e observação.
- Questões de múltipla escolha e atividades interativas de arrastar e soltar.
- Indicador de progresso e pontuação durante a partida.
- Opção para jogar novamente ou voltar ao menu.

## Tecnologias

- React 19
- TypeScript 6
- Vite 8
- dnd-kit
- CSS

## Executar o projeto localmente

Para desenvolvimento ou contribuição, é necessário ter Node.js 20.19+ (ou 22.12+) e npm instalados.

```bash
git clone (https://github.com/Pozzan07/Curriculariza-o-grupo-17)
cd Curriculariza-o-grupo-17
npm install
npm run dev
```

O Vite exibirá no terminal o endereço local para abrir no navegador.
